# 米奇 1.3.1 · 修复 Windows 点击互动

- 修复 Windows 左键单击、双击和连续点击不触发：仅在实际移动超过拖动阈值后启动系统拖动，保留完整点击事件。
- 统一单击、双击与连续点击判定，不依赖 WebView 的鼠标事件计数；每组连续点击只触发对应的一个动作。
- 拖动、取消和焦点切换会取消待触发点击，防止拖动后意外播放互动动作。
- 保留喝水记录、七天趋势、陪伴日记和原有动作配置。

## 下载

- macOS Apple Silicon：`Mickey-macOS-arm64-v1.3.1.zip`
- Windows 10/11 x64：`Mickey-v1.3.1-windows-x86_64-setup.exe`
- 已安装版可右键选择“更新米奇版本”。

## 验证

鼠标事件回归测试覆盖单击、双击、三连击、多次点击、拖动阈值、取消、失焦和右键。Windows 原生 WebView2 实机交互仍需人工验收。
