# 米奇 1.3.0 · 近七天喝水记录

## 产品入口

- **喝水与记录**：记录一杯水、今天总量、近七天趋势、一句话总结及逐日记录明细。
- **米奇陪伴日记**：右键菜单的独立入口，生成当天陪伴日记，继续支持复制图片或文字。
- 喝水面板不再承载日记分享入口。

## 数据口径

近七天包括本地日期的今天和此前六天。使用已有 `hydration-records.json`，无需迁移或删除历史记录。

图表按日汇总记录水量，点击柱子切换明细（时间、水量、主动 / 提醒来源）。无记录显示“—”，不推断当天实际喝水量。今天标记为“仍在累计”。

总结在本地生成：空记录给首次记录提示；昨天和前天都有记录时描述两日记录量差值；其余情况描述七天有记录的天数与总量。不会根据缺失数据推断下降，不做健康达标判断。

手动打开的喝水面板保持打开；提醒打开的面板在喝水动画结束后关闭，查看某天明细时取消自动关闭。

## 工程与验证

- 新增七日统计命令，跨月、跨年、闰日使用日历运算。
- 记录及撤销发出数据变化事件，图表与明细同步更新。
- 主窗口尺寸不变；侧窗边缘定位并限制在屏幕内，较小屏幕支持滚动。
- 日记与喝水共用侧窗，采用独立展示模式和异步请求保护，避免旧日记请求覆盖新面板。
- 撤销菜单只交给主窗口处理，避免两个窗口重复撤销。
- 36 项 Rust 核心测试、3 项 JavaScript 总结测试和 macOS 更新集成测试通过。
- 使用虚构记录验证新增、撤销、按日查看、空状态、读取失败和独立日记预览；演示记录不会写入用户真实喝水文件。

记录文件读取或解析失败时，会显示读取失败；新增和撤销不会覆盖异常的原文件。

## 下载与安装

- macOS Apple Silicon：[Mickey-macOS-arm64-v1.3.0.zip](https://github.com/Zimzheng/meowMickey/releases/download/v1.3.0/Mickey-macOS-arm64-v1.3.0.zip)。解压后覆盖安装“米奇.app”。
- Windows 10/11 x64：[Mickey-v1.3.0-windows-x86_64-setup.exe](https://github.com/Zimzheng/meowMickey/releases/download/v1.3.0/Mickey-v1.3.0-windows-x86_64-setup.exe)。运行中文安装向导，当前用户安装。
- 两个平台均提供签名更新入口。旧版右键“更新米奇版本”即可检查更新。
- Intel Mac、Windows ARM 与 Linux 安装包暂未发布；Windows 原生交互仍需人工验收。
